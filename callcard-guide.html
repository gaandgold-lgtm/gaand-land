① 설치하기

1
크롬으로 이 페이지 열기

2
[앱 내려받기] 누르기
다운로드가 끝나면 알림이나 내 파일 → 다운로드에서 callcard.apk를 눌러요.
3
설치 누르기
경고가 뜨면 아래 표대로 하면 돼요. 앱스토어에 없는 앱이라 뜨는 안내예요.
이런 말이 뜨면이렇게 하세요

② 처음 설정 (한 번만)

1
① 권한 허용하기
전화 · 통화기록 · 문자 · 알림을 모두 허용해요.
허용 버튼이 회색이거나 "제한된 설정"이라고 나오면: 설정 → 애플리케이션 → 가앤 콜명함 → 오른쪽 위 ⋮ → 제한된 설정 허용 후 다시 누르기
2
② 배터리 절전에서 빼기
허용을 눌러요. 안 하면 알림이 늦게 뜨거나 안 떠요.
3
내 정보 넣기
상호 · 이름 · 연락처 · 링크(블로그·명함 페이지 등)를 적고 저장하기. 문구 속 {상호} {이름} {연락처} {링크} 자리에 자동으로 들어가요.
4
문구 다듬기
받은 전화 · 건 전화 · 부재중 전화마다 보낼 문구를 고치고 저장하기. 링크는 어디에 적어도 보낼 때 자동으로 맨 아래 줄로 옮겨져요.
5
명함 이미지 등록 (추천)
명함 이미지 고르기 → 갤러리에서 명함 사진 선택 → 문자에 명함 이미지 붙이기 켜기.
그림이 문자에 직접 붙어서, 받는 사람 폰 설정과 상관없이 명함이 보여요.
6
테스트
테스트 칸에 내 번호 → 테스트 알림 띄우기 → [보내기] → 문자 앱에서 전송. 내 폰으로 명함 문자가 오면 끝!

③ 사용 신청

앱의 사용 기간 칸에서 원하는 기간을 고르고 사용 신청 문자 보내기를 누르면, 기간과 기기번호가 담긴 문자가 자동으로 써져요. 그대로 보내 주세요.

등록이 끝났다는 답장을 받으면 앱에서 사용 기간 다시 확인을 눌러요. ✓ 사용 중이 뜨면 바로 쓸 수 있어요.
