왜 가앤 콜명함인가요

내가 누를 때만 보내요. 가족·지인에게 엉뚱한 홍보 문자가 가는 일이 없어요.
내 번호, 내 요금제로 보내요. 문자 무제한 요금제면 추가 문자 요금이 없어요.
3가지 문구를 따로. 받은 전화 / 건 전화 / 부재중 전화마다 다른 문구, 상호·이름·링크 자동 입력.
같은 번호는 하루 한 번만. 하루에 여러 번 통화해도 한 번만 물어봐요.
기록이 밖으로 안 나가요. 통화 기록과 번호는 휴대폰 안에서만 쓰여요.

입금 확인 후 바로 사용 기간을 열어드려요. 문자 요금은 사용하시는 통신 요금제를 따라요.

시작하는 법

  1. 위 앱 내려받기 → 받은 파일을 눌러 설치. "출처를 알 수 없는 앱"이 뜨면 이 출처 허용.
  2. "자동 차단"으로 막히면 설정 → 보안 및 개인정보 보호 → 자동 차단 잠깐 끄기. Play 프로텍트 경고는 그래도 설치.
  3. 앱에서 ① 권한 허용하기, ② 배터리 절전에서 빼기.
  4. 내 정보(상호·이름·연락처·링크) 입력 → 저장하기.
  5. 테스트에 내 번호 넣고 테스트 알림 띄우기로 확인하면 끝!
권한 버튼이 회색이면: 설정 → 애플리케이션 → 가앤 콜명함 → 오른쪽 위 ⋮ → 제한된 설정 허용.

구매 · 문의

앱을 설치하고 구매 문의 문자 보내기를 누르면 기기번호가 자동으로 들어가요. 입금 확인 후 사용 기간을 열어드리면 따로 입력할 것 없이 바로 쓸 수 있어요.
