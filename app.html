가앤 명함문자 앱

통화가 끝나면 "명함 문자 보낼까요?" 알림이 떠요. [보내기]를 누를 때만 문자가 가요.

📥 앱 내려받기

설치 순서

  1. 위 앱 내려받기를 누르고, 다 받아지면 알림에서 gaand-callback.apk를 눌러요.
  2. "설치할 수 없음 / 출처를 알 수 없는 앱" 창이 뜨면 설정 → 이 출처 허용 켜고 뒤로 가기 → 설치.
  3. "자동 차단(Auto Blocker)으로 차단됨"이 뜨면: 설정 → 보안 및 개인정보 보호 → 자동 차단 끄기 → 다시 설치. 설치 후 다시 켜도 돼요.
  4. "Play 프로텍트" 경고가 뜨면 세부정보 더보기 → 그래도 설치.
  5. 앱을 열고 ① 권한 허용하기 → 나오는 창 모두 허용.
  6. ② 배터리 절전에서 빼기 → 허용.
  7. 맨 아래 테스트에 내 번호를 적고 테스트 알림 띄우기 → 알림에서 보내기 → 내 폰에 문자가 오면 끝!
권한 허용 창이 안 뜨거나 회색이면
설정 → 애플리케이션 → 가앤 명함문자 → 오른쪽 위 ⋮ → 제한된 설정 허용 → 앱으로 돌아와 다시 ①.
모두의 콜백을 쓰고 있다면
문자가 두 번 가지 않게 모두의 콜백은 꺼주세요.
새 버전으로 바꿀 때
